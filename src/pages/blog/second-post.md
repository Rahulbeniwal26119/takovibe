# Getting Started with Astro

Astro is an amazing static site generator that makes building websites fun and efficient.

## Key Features

1. **Component Islands**: Load JavaScript only where needed
2. **Fast by Default**: Built for speed and performance
3. **Easy to Learn**: Familiar syntax for web developers

## Why Choose Astro?

Astro provides an excellent developer experience while ensuring top-notch performance for your users.
