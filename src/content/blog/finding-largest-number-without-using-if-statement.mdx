Most of us solve “find the largest number in a list” with a simple if.  
But what if we put a restriction: **no if allowed?** 🤔

---

## Cheating: Using `max()` Without If

```python
largest = numbers[0]
for num in numbers:
    largest = max(largest, num)

print(largest)  # 11
```

This is still “cheating” because `max()` internally compares. Let’s go bitwise now. 🚀

---

## Approach 1: Max of Two Numbers with Pure Bitwise Math

```python
from functools import reduce

def max_no_if(a, b):
    return a ^ ((a ^ b) & -(a < b))

numbers = [4, 9, 2, 11, 7]
largest = reduce(max_no_if, numbers)

print(largest)
```

### How does this work?

1. `(a < b)` → returns 1 if true, 0 if false.  
2. `-(a < b)` → converts that into either all ones (-1) or all zeros (0).  
3. `(a ^ b)` → highlights the different bits.  
4. `&` with the mask chooses whether to keep b or a.  
5. Finally, `a ^ (...)` selects the bigger number.

#### Example 1: `a = 11, b = 7`

- `a ^ b = 12`  
- `(a < b) = 0`  
- Mask = 0 → `a ^ 0 = 11` ✅

#### Example 2: `a = 5, b = 10`

- `a ^ b = 15`  
- `(a < b) = 1 → -1`  
- `15 & -1 = 15`  
- `a ^ 15 = 10` ✅

## Approach 2: Using Sign Bit

```python
def max_bitwise(a, b):
    diff = a - b
    k = (diff >> 31) & 1   # Extract sign bit (1 if negative, 0 if positive)
    return a - k * diff
```

### Explanation

- If `a < b`, then `diff` is negative → sign bit = 1 → return `b`.  
- Otherwise, return `a`.  

#### Example: `a = 11, b = 7`

- `diff = 4 → sign bit = 0`  
- Result = `11` ✅

## Why Bother Avoiding If?

At first, it might feel silly to avoid such a basic keyword. But thinking this way has benefits:

- You’ll discover built-in tools that make your code shorter and more efficient.  
- You’ll train yourself to approach problems from multiple perspectives.
