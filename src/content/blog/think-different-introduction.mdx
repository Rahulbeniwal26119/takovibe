## Example: The Classic Two Sum Problem

Let's start with a simple example to demonstrate the "Think Different" philosophy.

### Problem Statement
Given an array of integers and a target sum, find two numbers that add up to the target.

### Conventional Approach
```python
def two_sum_conventional(nums, target):
    seen = {}
    for i, num in enumerate(nums):
        complement = target - num
        if complement in seen:
            return [seen[complement], i]
        seen[num] = i
    return []
```

**Analysis**: O(n) time, O(n) space. Standard hash map approach.

### Think Different Approach: Mathematical Insight
```python
def two_sum_mathematical(nums, target):
    # Sort with original indices
    indexed_nums = [(num, i) for i, num in enumerate(nums)]
    indexed_nums.sort()
    
    left, right = 0, len(nums) - 1
    
    while left < right:
        current_sum = indexed_nums[left][0] + indexed_nums[right][0]
        
        if current_sum == target:
            return [indexed_nums[left][1], indexed_nums[right][1]]
        elif current_sum < target:
            left += 1
        else:
            right -= 1
    
    return []
```

**Analysis**: O(n log n) time, O(n) space. But what if we have multiple queries?

### Think Different Approach: Preprocessing for Multiple Queries
```python
class TwoSumSolver:
    def __init__(self, nums):
        self.original = nums
        self.sorted_pairs = sorted((num, i) for i, num in enumerate(nums))
        
    def find_two_sum(self, target):
        left, right = 0, len(self.sorted_pairs) - 1
        
        while left < right:
            current_sum = self.sorted_pairs[left][0] + self.sorted_pairs[right][0]
            
            if current_sum == target:
                return [self.sorted_pairs[left][1], self.sorted_pairs[right][1]]
            elif current_sum < target:
                left += 1
            else:
                right -= 1
        
        return []

# Usage for multiple queries
solver = TwoSumSolver([2, 7, 11, 15])
result1 = solver.find_two_sum(9)   # [0, 1]
result2 = solver.find_two_sum(13)  # [0, 2]
```

**Analysis**: O(n log n) preprocessing, O(n) per query. Better for multiple queries!
