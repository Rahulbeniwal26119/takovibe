👉 **Finding the square root of a number without using any built-in functions.**

Normally, you’d just do this in Python:

```python
import math
print(math.sqrt(25))  # 5.0
```

But where’s the fun in that? 😏  
Let’s explore two methods that show how computers and math legends solved this problem.

---

## 🔹 Method 1: Binary Search (Guess the Number)

Imagine we want √25.  
We know it must lie between 0 and 25. Now we repeatedly guess the middle and shrink our range:

1. Range `[0, 25]` → mid = 12.5 → `12.5² = 156.25` → too high.  
2. Range `[0, 12.5]` → mid = 6.25 → `39.06` → too high.  
3. Range `[0, 6.25]` → mid = 3.125 → `9.76` → too low.  
4. Range `[3.125, 6.25]` → mid = 4.6875 → `21.97` → close but low.  
5. Range `[4.6875, 6.25]` → mid = 5.46875 → `29.91` → too high.  

Keep going like this—each step halves the range until we close in around 5.  

```python
import math

def sqrt_binary_search(num, precision=1e-6):
    low, high = 0, num
    while high - low > precision:
        mid = (high + low) / 2
        if mid * mid < num:
            low = mid
        else:
            high = mid
    return (low + high) / 2

print(round(math.sqrt(101), 6) == round(sqrt_binary_search(101), 6)) # True
```

✅ This works reliably, though it may take many steps.

## 🔹 Method 2: Newton-Raphson (Smarter Guessing)

Newton’s method is much faster. It improves the guess using:

$$
g_{\text{next}} = \frac{g + \frac{x}{g}}{2}
$$

Let’s try with x = 25:

1. Start guess: 12.5 → next = 7.25  
2. Now guess: 7.25 → next ≈ 5.34  
3. Now guess: 5.34 → next ≈ 5.00 🎯  

Boom—after just 3 steps, we’re basically at 5.

```python
def sqrt_newton(x, precision=1e-6):
    guess = x / 2
    while abs(guess * guess - x) > precision:
        print(f"Guess: {guess:.6f}, Square: {guess * guess:.6f}")
        guess = (guess + x / guess) / 2
    return guess

import math
print(round(math.sqrt(25), 6) == round(sqrt_newton(25), 6))  # True
print(round(math.sqrt(101), 6) == round(sqrt_newton(101), 6)) # True
```

Newton’s method converges incredibly fast. CPUs and programming languages internally rely on similar iterative methods to approximate roots.

## 💡 Visualizing Newton’s Method

Newton’s method isn’t just numbers—it’s geometry.  
We’re solving:

$$
f(g) = g^2 - x = 0
$$

Each step:  
- Start with a guess `g` on the parabola.  
- Draw the tangent line at that point.  
- See where it intersects the x-axis → that’s the new guess.  

Iteration after iteration, the tangent “slides” us closer to the true root.
