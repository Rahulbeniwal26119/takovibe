# Fine-tuning Large Language Models: A Complete Guide

Fine-tuning Large Language Models (LLMs) has become essential for creating AI systems that excel in specific domains and tasks. This comprehensive guide will walk you through the entire process, from understanding the fundamentals to implementing production-ready fine-tuning pipelines.

## Understanding Fine-tuning

Fine-tuning is the process of taking a pre-trained language model and adapting it to perform better on specific tasks or domains by training it on task-specific data.

### Why Fine-tune?

1. **Domain Adaptation**: Models perform better on specialized content
2. **Task Optimization**: Improved performance on specific tasks
3. **Efficiency**: Better results with smaller models
4. **Customization**: Tailored responses and behavior

## Types of Fine-tuning

### 1. Full Fine-tuning
Training all model parameters on your dataset.

```python
import torch
from transformers import AutoModel, AutoTokenizer, Trainer, TrainingArguments

model = AutoModel.from_pretrained("microsoft/DialoGPT-medium")
tokenizer = AutoTokenizer.from_pretrained("microsoft/DialoGPT-medium")

# Full fine-tuning configuration
training_args = TrainingArguments(
    output_dir="./results",
    num_train_epochs=3,
    per_device_train_batch_size=4,
    gradient_accumulation_steps=2,
    warmup_steps=500,
    weight_decay=0.01,
    logging_dir="./logs",
)
```

### 2. Parameter-Efficient Fine-tuning (PEFT)
Training only a subset of parameters for efficiency.

#### LoRA (Low-Rank Adaptation)
```python
from peft import LoraConfig, get_peft_model, TaskType

    lora_dropout=0.1,
    target_modules=["q_proj", "v_proj"]
```

## Data Preparation

### Dataset Requirements

1. **Quality over Quantity**: Clean, relevant data is crucial
2. **Diversity**: Representative samples of your target domain
3. **Format Consistency**: Proper structure for your task type

### Data Processing Pipeline

```python
import pandas as pd
from datasets import Dataset
from transformers import DataCollatorForLanguageModeling

def prepare_dataset(data_path):
    # Load and clean data
    df = pd.read_csv(data_path)
    df = df.dropna()
    
    # Create dataset
    dataset = Dataset.from_pandas(df)
    
    # Tokenize
    def tokenize_function(examples):
        return tokenizer(
            examples["text"],
            truncation=True,
            padding=True,
            max_length=512
        )
    
    tokenized_dataset = dataset.map(tokenize_function, batched=True)
    return tokenized_dataset

# Data collator for language modeling
data_collator = DataCollatorForLanguageModeling(
    tokenizer=tokenizer,
    mlm=False  # Set to True for masked language modeling
)
```

## Training Strategies

### Supervised Fine-tuning (SFT)

```python
from transformers import Trainer

class CustomTrainer(Trainer):
    def compute_loss(self, model, inputs, return_outputs=False):
        labels = inputs.get("labels")
        outputs = model(**inputs)
        logits = outputs.get("logits")
        
        # Custom loss calculation
        loss_fn = torch.nn.CrossEntropyLoss()
        loss = loss_fn(logits.view(-1, logits.size(-1)), labels.view(-1))
        
        return (loss, outputs) if return_outputs else loss

trainer = CustomTrainer(
    model=model,
    args=training_args,
    train_dataset=train_dataset,
    eval_dataset=eval_dataset,
    data_collator=data_collator,
    tokenizer=tokenizer,
)
```

### Reinforcement Learning from Human Feedback (RLHF)

```python
from trl import PPOTrainer, PPOConfig
from transformers import pipeline

# Initialize reward model
reward_model = pipeline("text-classification", model="sentiment-analysis-model")

def compute_reward(generated_text):
    sentiment = reward_model(generated_text)[0]
    return sentiment["score"] if sentiment["label"] == "POSITIVE" else -sentiment["score"]

# PPO training configuration
ppo_config = PPOConfig(
    model_name="gpt2",
    learning_rate=1.41e-5,
    batch_size=256,
    mini_batch_size=1,
)

ppo_trainer = PPOTrainer(
    config=ppo_config,
    model=model,
    tokenizer=tokenizer,
    dataset=dataset,
    compute_reward=compute_reward,
)
```

### Gradient Management

```python
# Gradient clipping
torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)

# Gradient accumulation
accumulation_steps = 4
loss = loss / accumulation_steps
loss.backward()

if (step + 1) % accumulation_steps == 0:
    optimizer.step()
    scheduler.step()
    optimizer.zero_grad()
```

### Memory Optimization

```python
# Mixed precision training
from torch.cuda.amp import GradScaler, autocast

scaler = GradScaler()

with autocast():
    outputs = model(**inputs)
    loss = outputs.loss

scaler.scale(loss).backward()
scaler.step(optimizer)
scaler.update()
```

## Advanced Techniques

### Multi-Task Learning

```python
class MultiTaskModel(torch.nn.Module):
    def __init__(self, base_model, task_configs):
        super().__init__()
        self.base_model = base_model
        self.task_heads = torch.nn.ModuleDict({
            task: torch.nn.Linear(base_model.config.hidden_size, config["num_labels"])
            for task, config in task_configs.items()
        })
    
    def forward(self, input_ids, task_name, **kwargs):
        outputs = self.base_model(input_ids, **kwargs)
        hidden_states = outputs.last_hidden_state
        task_output = self.task_heads[task_name](hidden_states)
        return task_output
```

### Curriculum Learning

```python
def curriculum_scheduler(epoch, total_epochs):
    """Gradually increase task difficulty"""
    difficulty_level = min(epoch / (total_epochs * 0.3), 1.0)
    return difficulty_level

# Apply to data sampling
def get_curriculum_data(dataset, difficulty_level):
    # Filter data based on difficulty
    filtered_data = dataset.filter(lambda x: x["difficulty"] <= difficulty_level)
    return filtered_data
```

## Troubleshooting Common Issues

### Overfitting
- Reduce learning rate
- Add regularization
- Increase dataset size
- Early stopping

### Catastrophic Forgetting
- Lower learning rates
- Gradual unfreezing
- Elastic weight consolidation
- Multi-task training

### Memory Issues
- Gradient checkpointing
- Model parallelism
- Smaller batch sizes
- Mixed precision training
