Temporary files are everywhere in development — system maintenance, file uploads, downloads, sending reports in emails, and more.
As a developer, you’ll often run into them, so let’s master Python’s `tempfile` module with real-world examples.

---

## 1. Creating a Temporary File

```python
from tempfile import TemporaryFile

with TemporaryFile('w+t') as f:
    f.write('First Temp File\n')
    f.seek(0)
    print(f.read())
```

✔️ This creates an unnamed temporary file in `w+t` mode (write + text), allowing both reading and writing.

You can also use it without context managers (not recommended, but possible):

```python
f = TemporaryFile('w+t')
f.write('Hello World\n')
f.seek(0)
print(f.read())
f.close()
```

👉 Always prefer context managers to handle cleanup automatically.

It supports the same options as Python’s built-in `open`:

```python
with TemporaryFile('w+t', encoding='utf-8', errors='ignore') as f:
    f.write("Hello with encoding\n")
```

---

## 2. Named Temporary Files

On most Unix-based systems, `TemporaryFile` creates files without a directory entry.
But sometimes you need a file to persist in `/tmp/`. Use `NamedTemporaryFile`:

```python
from tempfile import NamedTemporaryFile

with NamedTemporaryFile('w+t') as f:
    print('filename is:', f.name)
# filename is: /tmp/tmp0w4nxt_u
```

To **persist files even after closing**:

```python
NamedTemporaryFile('w+t', delete=False)
```

---

## 3. Creating Temporary Directories

Sometimes you need both temp files and temp directories:

```python
from tempfile import TemporaryDirectory, NamedTemporaryFile

with TemporaryDirectory() as dirname:
    print('directory is:', dirname)

    with NamedTemporaryFile('w', dir=dirname) as f:
        print('filename is:', f.name)
        f.write('Hello World\n')
```

✔️ This first creates a temp directory, then places a temp file inside it.

---

## 4. Customizing Prefix, Suffix, and Directory

You can define naming conventions for temporary files:

```python
from tempfile import NamedTemporaryFile

with NamedTemporaryFile(prefix="secret_", suffix=".txt", dir='/tmp/') as f:
    print('Filename is:', f.name)
```

---

## 5. Changing Default Temp File Location

Sometimes you want all temporary files for a module in the same custom directory.
Instead of specifying `dir` everywhere, override the default:

```python
import tempfile
tempfile.tempdir = '/home/rahul/temp'

print(tempfile.gettempdir())

with tempfile.TemporaryDirectory() as dirname:
    print('dirname is:', dirname)

# /home/rahul/temp
# dirname is: /home/rahul/temp/tmp8lgzrf18
```

---

## Wrapping Up

You’ve now seen how to use:

- `TemporaryFile` → unnamed temporary files.
- `NamedTemporaryFile` → persisted files with paths.
- `TemporaryDirectory` → disposable directories.
- Custom prefixes, suffixes, and locations.

👉 Next time you need temp storage for uploads, downloads, or caching, you’ll know exactly how to use Python’s `tempfile` like a pro.
