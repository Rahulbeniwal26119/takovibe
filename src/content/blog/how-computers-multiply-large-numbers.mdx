## Multiplying Numbers in Python

At first glance, it seems like Python just uses the `*` operator:

```python
x = 123456789123456789
y = 987654321987654321
print(x * y)
```

But under the hood, things are smarter.  

For small numbers, Python uses **hardware multiplication**.  
For bigger numbers, Python switches to **Karatsuba’s algorithm**.  
And for *huge* numbers, it even uses **Toom-Cook** and **FFT-based methods**.

---

## The Grade-School Method

Think back to how we multiply numbers on paper:

```
        1234
   ×    5678
   ------------
        9872   (1234 × 8)
       8638    (1234 × 70)
      7404     (1234 × 600)
     6170      (1234 × 5000)
   ------------
     7006652
```

This approach requires **O(n²) multiplications** for n-digit numbers.  
Fine for small inputs, but **too slow** once numbers grow into hundreds or thousands of digits.

---

## Enter Karatsuba’s Algorithm

In 1960, Anatoly Karatsuba introduced a clever trick:  
**Do it with 3 multiplications instead of 4.**

Here’s a Python implementation:

```python
from math import floor

def Karatsuba(x, y):
    if x < 10 or y < 10:
        return x * y

    # Find size of smaller number
    n = min(len(str(x)), len(str(y)))
    m = floor(n / 2)

    # Split x and y into high and low parts
    high1 = floor(x / 10 ** m)
    low1 = x % 10 ** m
    high2 = floor(y / 10 ** m)
    low2 = y % 10 ** m

    # Recursively compute three products
    z0 = Karatsuba(low1, low2)
    z1 = Karatsuba(low1 + high1, low2 + high2)
    z2 = Karatsuba(high1, high2)

    # Combine results
    return (z2 * 10 ** (2 * m)) + ((z1 - z2 - z0) * 10 ** m) + z0

assert Karatsuba(1234, 4567) == 1234 * 4567
assert Karatsuba(112121, 1212) == 112121 * 1212
```

---

## 🔎 Walkthrough Example (1234 × 5678)

Let’s break it down step by step:

- `x = 1234 → high1=12, low1=34`  
- `y = 5678 → high2=56, low2=78`

Now compute:

- `z0 = Karatsuba(34, 78) = 2652`  
- `z1 = Karatsuba(46, 134) = 6164`  
- `z2 = Karatsuba(12, 56) = 672`

Combine:

```
result = (672 * 10^4) + ((6164 - 672 - 2652) * 10^2) + 2652
       = 7006652 ✅
```

## Intuition Behind Karatsuba

For two-digit numbers:

```
x = 10a + b
y = 10c + d
```

The grade-school way:

```
x * y = ac·100 + ad·10 + bc·10 + bd
```

That’s **4 multiplications**: ac, ad, bc, bd.

Karatsuba’s trick:

```
(a+b)(c+d) = ac + ad + bc + bd
```

So:

```
ad + bc = (a+b)(c+d) - ac - bd
```

Which means we only need:

- ac  
- bd  
- (a+b)(c+d)  

👉 Just **3 multiplications** instead of 4!

---

## Wrap-Up

Python’s multiplication isn’t always what it looks like:

- **Small numbers** → hardware multiplication  
- **Large numbers** → Karatsuba algorithm  
- **Huge numbers** → Toom-Cook & FFT-based algorithms  

This is a perfect example of how computers use *mathematical tricks* to make fundamental operations faster.
