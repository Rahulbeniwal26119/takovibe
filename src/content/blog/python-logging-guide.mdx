Logging is a critical element of software development, and it plays an essential role in comprehending and resolving application issues. This process involves systematically recording events, activities, or messages created by a program while it runs. The primary aim of logging is to offer valuable insights into the program's behavior, status, and errors, which can assist developers in debugging problems, monitoring performance, and supporting production systems.

---

## Important Terms Regarding Logging

- **Loggers**: Objects from Python’s `logging` module responsible for emitting log messages. They can have different configurations like where to write logs, formatting, etc.
- **Log Level**: Indicates the significance of log messages.
- **Handler**: Defines where logs should be sent (console, file, remote server). Multiple handlers can be attached to a single logger.
- **Formatter**: Defines the format of log messages (timestamps, log level, logger name, etc.).
- **Filter**: Discards log messages based on criteria (processed only if `Filter` returns true).
- **Root Logger**: The default logger provided by the `logging` module. All messages pass through it if no custom logger is defined.
- **Propagation**: Log messages from child loggers can be passed to parent loggers. Enabled by default.

---

## Understanding Logging Levels

Logging levels help categorize the importance of the information being logged:

- **DEBUG**: Detailed information useful for debugging (development environment).
- **INFO**: General runtime information (application state, events).
- **WARNING**: Indicates potential problems that might lead to errors.
- **ERROR**: A serious issue that requires attention but doesn’t stop the application.
- **CRITICAL**: Indicates critical errors or crashes requiring immediate fixes.

```python
CRITICAL = 50
FATAL = CRITICAL
ERROR = 40
WARNING = 30
WARN = WARNING
INFO = 20
DEBUG = 10
NOTSET = 0
```

The logger only logs levels equal to or higher than the configured level.

## Root Logger Example

```python
import logging

logging.debug('This is a debug message')  # Not printed
logging.info('This is an info message')   # Not printed
logging.warning('This is a warning message')
logging.error('This is an error message')
logging.critical('This is a critical message')
```

Output:

```
WARNING:root:This is a warning message
ERROR:root:This is an error message
CRITICAL:root:This is a critical message
```

By default, the root logger is set to **WARNING**, so `DEBUG` and `INFO` won’t be shown.

```python

logging.basicConfig(level=logging.DEBUG,
                    format='%(asctime)s - %(levelname)s - %(message)s',
```

## Loggers, Formatters, and Handlers

### Creating a Logger

```python
import logging

logger = logging.getLogger(__name__)
logger.setLevel(logging.DEBUG)

logger.debug("Hello World")
```

Output:

```
DEBUG:__main__:Hello World
```

---

### Adding Formatters

```python
import logging

logger = logging.getLogger(__name__)
logger.setLevel(logging.DEBUG)

stream_handler = logging.StreamHandler()
console_formatter = logging.Formatter('%(asctime)s - %(name)s - %(levelname)s - %(message)s')

stream_handler.setFormatter(console_formatter)
logger.addHandler(stream_handler)

logger.debug('This is a debug message')
```

Output:

```
2023-07-29 08:24:29,818 - __main__ - DEBUG - This is a debug message
```

---

### Console vs File Handler Example

```python
import logging

logger = logging.getLogger(__name__)
logger.setLevel(logging.DEBUG)

stream_handler = logging.StreamHandler()
console_formatter = logging.Formatter('%(asctime)s - %(name)s - %(levelname)s - %(message)s')

file_handler = logging.FileHandler('file.log')
file_handler.setLevel(logging.WARNING)
file_formatter = logging.Formatter('%(asctime)s - %(name)s - %(levelname)s - %(message)s - %(lineno)d')

stream_handler.setFormatter(console_formatter)
file_handler.setFormatter(file_formatter)

logger.addHandler(stream_handler)
logger.addHandler(file_handler)

logger.debug('This is a debug message')
logger.warning('This is a warning message')
```

Console Output:

```
2023-07-29 08:28:20,324 - __main__ - DEBUG - This is a debug message
2023-07-29 08:28:20,325 - __main__ - WARNING - This is a warning message
```

File Output:

```
2023-07-29 08:28:20,325 - __main__ - WARNING - This is a warning message - 20
```

## Placeholders for Formatters

Some commonly used placeholders are:

- `%(asctime)s` → Timestamp of log record (string).
- `%(name)s` → The name of the logger.
- `%(levelname)s` → Log level name (DEBUG, INFO, WARNING, ERROR, CRITICAL).
- `%(message)s` → The actual log message.
- `%(lineno)d` → Line number in source code.
- `%(funcName)s` → Function/method name.
- `%(threadName)s` → Thread name.
- `%(thread)d` → Thread ID.
- `%(process)d` → Process ID.
- `%(processName)s` → Process name.
- `%(pathname)s` → Full pathname of the source file.
- `%(filename)s` → Filename only.
- `%(module)s` → Python module name.

## Filters

Filters can be applied at two levels:

1. **Logger Level**
2. **Handler Level**

### Logger-Level Filter

```python
import logging

logger = logging.getLogger(__name__)
logger.setLevel(logging.DEBUG)

class SensitiveInfoFilter(logging.Filter):
    def filter(self, record):
        if any(sensitive_word in record.msg for sensitive_word in ('key', 'secret', 'password')):
            return False
        return True

logger.addFilter(SensitiveInfoFilter())

handler = logging.StreamHandler()
handler.setLevel(logging.DEBUG)
logger.addHandler(handler)

logger.debug('password: 123456')
logger.info('key: 123456')
logger.info("fine")
```

Output:

```
fine
```

---

### Handler-Level Filter

```python
import logging

logger = logging.getLogger(__name__)
logger.setLevel(logging.DEBUG)

class SensitiveInfoFilterConsole(logging.Filter):
    def filter(self, record):
        if any(sensitive_word in record.msg for sensitive_word in ('key', 'secret', 'password')):
            return False
        return True

handler = logging.StreamHandler()
handler.setLevel(logging.DEBUG)
handler.addFilter(SensitiveInfoFilterConsole())
logger.addHandler(handler)

file_handler = logging.FileHandler('log.log')
file_handler.setLevel(logging.DEBUG)
logger.addHandler(file_handler)

logger.debug('password: 123456')
logger.info('key: 123456')
logger.info("fine")
```

Console Output:

```
fine
```

File Output:

```
password: 123456
key: 123456
fine
```

## Propagation

Propagation passes log messages from a logger to its parent loggers.

Steps in Logging:

1. Emit log message.
2. Logger handler processes it.
3. Propagates to root logger.
4. Parent logger processes it.
5. Root logger processes it.

```python
import logging

root_logger = logging.getLogger()
root_logger.setLevel(logging.WARNING)

console_handler = logging.StreamHandler()
console_handler.setLevel(logging.WARNING)

formatter = logging.Formatter('%(asctime)s - %(levelname)s - %(message)s')
console_handler.setFormatter(formatter)

root_logger.addHandler(console_handler)

child_logger = logging.getLogger('child_logger')
child_logger.setLevel(logging.DEBUG)

child_logger.debug('This is a debug message')
child_logger.info('This is an info message')
child_logger.critical('This is a critical message by child')

root_logger.info('This is an info message root logger')
root_logger.warning('This is a warning message root logger')
```

Output:

```
2023-07-29 10:05:43,793 - CRITICAL - This is a critical message by child
2023-07-29 10:05:43,795 - WARNING - This is a warning message root logger
```

👉 If you add a handler to the child logger, messages will be handled by the child logger only.
