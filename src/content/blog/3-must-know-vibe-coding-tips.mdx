### 2. Use Single Shot or Few Shot Prompt Technique

Large Language Models (LLMs) are powerful — but to get the best results, you need to **guide them clearly**. Prompts work like instructions: the clearer and more structured you make them, the better the output.

One way to guide LLMs is by using **single-shot** or **few-shot** prompting.

> Ask LLMs how to ask better questions to them

#### i) Single Shot

You give the model **one example or one instruction**.
 It works well when your request is simple or familiar.

> **Prompt:**
>
>
>  
>
> *Design a login screen using Material 3 expressive UI.*

Here, the model has only one instruction and must generate the solution based on that single request.

#### ii) Few-Shot Prompt

Few-shot prompting is stronger because you provide 2–3 examples to show the model *how you want it to respond*.
 This helps the model understand style, structure, and the expected output.

> **Example 1:**
>
>
>  Design a profile screen using Material 3 expressive UI.
>
> **Example 2:**
>
>
>  Design a settings screen using Material 3 expressive UI.

Now the LLM understands the pattern:

* You want a UI design
* It should follow the Material 3 expressive style
* The output should likely follow a similar structure to earlier examples

Example might not be best, but you got the idea. The more context you provide to LLM, the better the result you can expect.

### 3. Let LLM code, but keep the design part to yourself

Coding and design are different responsibilities, and when I started as a developer, I used to think, *What does my manager do?*

We do all the coding, and they don’t seem to be coding at all. But now I realize they are doing one of the most important tasks of all:

> designing the system and distributing tasks to junior developers.

I have a classic example of how to reset a password:

* Send the user a password reset link containing a temporary signed token with the user’s email.
* When landing on the reset password page, first verify the signed token with the email included in the existing link, and provide a signed intermediate token for the reset password API, because it is not a good idea to keep that API open.
* Verify the signed intermediate token and reset the password.

But I realized the first changes made by the LLM agent were not up to security standards, and it could be a big trouble for me, resulting in account hijacks.
