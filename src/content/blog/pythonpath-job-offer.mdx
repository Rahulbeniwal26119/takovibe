# Understanding PYTHONPATH

## What is PYTHONPATH?

<div className="prose-base leading-relaxed">
<code>PYTHONPATH</code> is an environment variable that specifies additional directories for the Python interpreter to search for modules and packages. It acts as a supplement to Python's default module search path, allowing you to include custom directories.
</div>

Let's understand this with an example:

```text
.
├── main.py
└── package
    └── maths.py
```

<div className="bg-gray-50 dark:bg-gray-800 rounded-lg p-6 my-6">
Here's our `main.py`:

```python
from maths import add, sub

print(add(1, 2))
print(sub(1, 2))
```

And our `package/maths.py`:

```python
def add(a, b):
    return a + b

def sub(a, b):
    return a - b
```
</div>

When we try to run this:

```bash
>>> python3 main.py 
Traceback (most recent call last):
  File "/home/user/python/pth/main.py", line 1, in <module>
    from maths import add, sub
ModuleNotFoundError: No module named 'maths'
```

<div className="bg-yellow-50 dark:bg-yellow-900/20 border-l-4 border-yellow-500 p-4 my-6">
Python is looking for `maths` in the current directory only:

```python
['/home/user/python/pth', 
 '/usr/lib/python312.zip', 
 '/usr/lib/python3.12', 
 '/usr/lib/python3.12/lib-dynload', 
 '/usr/local/lib/python3.12/dist-packages', 
 '/usr/lib/python3/dist-packages']
```
</div>

## Solutions

### 1. Temporary Changes Without Export 

```bash
PYTHONPATH=./package python3 main.py
3
-1
```

### 2. Temporary Changes With Export

```bash
$ export PYTHONPATH=./package
$ python3 main.py 
3
-1
```

### 3. Making Permanent Changes in PYTHONPATH

<div className="bg-gray-50 dark:bg-gray-800 rounded-lg p-6 my-6">
Add to your `~/.bashrc` or `~/.bash_profile`:

```bash
export PYTHONPATH=$PYTHONPATH:~/python/pth/package
```

Or use this command:

```bash
echo 'export PYTHONPATH=$PYTHONPATH:~/python/pth/package' >> ~/.bashrc
source ~/.bashrc
```
</div>

## Alternative Code Solution

<div className="prose-base leading-relaxed">
If you need to modify the path in code (though not recommended), you can do:
</div>

```python
import sys

sys.path.append("./package")

from maths import add, sub

print(add(1, 2))  # Output: 3
print(sub(1, 2))  # Output: -1
```

## Conclusion

<div className="prose-base leading-relaxed">
Understanding <code>PYTHONPATH</code> is crucial for Python developers. While it might seem simple, proper management of Python's import system can prevent many common issues in larger projects. Remember:

- <code>PYTHONPATH</code> extends Python's module search path
- It can be modified temporarily or permanently
- Modifying it in code should be avoided when possible
- Always consider the implications for project portability

Whether you're working on small scripts or large applications, a solid understanding of PYTHONPATH will help you avoid common pitfalls in Python development.
</div>
