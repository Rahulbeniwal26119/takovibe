Python's **bytes** and **str** types often show similar behaviors, but they are not the same. In this guide, we'll use practical examples to uncover their differences and similarities.

---

## Bytes and String

### Bytes

Object of bytes contains raw, unsigned 8 bit values (most of the time displayed in ASCII Encoding).

Bytes can only represent unsigned 8 bit character.

```python
bstring = b'h\x65llo'
print(list(bstring))
print(bstring)
```

Output:

```python
[104, 101, 108, 108, 111]
b'hello'
```

```python
string = b"こんにちは"
print(string)
```

Output:

```python
SyntaxError: bytes can only contain ASCII literal characters
```

### String

Object of string contains Unicode code that represent character from human languages.

string represent multiple bytes Unicode characters.

```python
a = 'a\u0300 propos'
b = 'こんにちは'
print(a)
print(b)
```

Output:

```python
à propos
こんにちは
```

## Conversion between `str` and `bytes`

While converting from bytes to string, encoding must be specified or OS encoding will be considered as default.

```python
import locale

# get os default encoding
os_default_encoding = locale.getpreferredencoding()


def to_str(string, encoding=os_default_encoding):
    if isinstance(string, bytes):
        return string.decode(encoding)
    return string


def to_bytes(string, encoding=os_default_encoding):
    if isinstance(string, str):
        return string.encode(encoding)
    return string


string = "こんにちは"
encoded_string = to_bytes(string)
decoded_string = to_str(encoded_string)
wrong_decoded_string = to_str(encoded_string, "latin-1")

print(encoded_string)
print(decoded_string)
print(wrong_decoded_string)
```

Output:

```python

こんにちは
```

## Diff between `str` and `bytes`

### 1. Behaves differently on applying `list`.

```python
String1 = b"String"
String2 = "String"
print(list(String1))
print(list(String2))
```

Output:

```python
[83, 116, 114, 105, 110, 103]
['S', 't', 'r', 'i', 'n', 'g']
```

### 2. Comparison Operators

```python
assert b'hello' > b'Hello'
assert 'hello' > 'Hello'
```

bytes can be compared to bytes only and string to string only.

```python
assert 'hello' > 'Hello'
```

Output:

```python
TypeError: '>' not supported between instances of 'bytes' and 'str'
```

equality check is an exception in this case because instead of exception it will always yield False even same character there.

```python
assert not b'hello' == 'hello'
```

### 3. String Interpolation

bytes can not substituted by string:

```python
print(b'color %s' % b'red')
print('color %s' % 'red')
```

Output:

```python
b'color red'
color red
```

```python
print(b'color %s' % 'red')
```

Output:

```python
TypeError: %b requires a bytes-like object, or an object that implements __bytes__, not 'str'
```

but string can be substituted by bytes but result is not what we expecting.

```python
print('color %s' % b'red')
```

Output:

```python
color b'red'
```

---

## Conclusion

String and Bytes are two independent classes. String is for human language character representation, but Bytes is for storing data in 8 bits and representing that information as a string.
