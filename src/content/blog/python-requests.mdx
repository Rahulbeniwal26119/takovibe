World is evolving fast 😀 — everything is connected to the internet: games, video calls, chatting, and countless other things. In all of these, one thing is common: **data transfer**.

Python provides a powerful library — `requests` — that simplifies the process of sending and receiving HTTP requests, consuming APIs, and retrieving valuable data.

## Brief Intro to HTTP and Its Components

HTTP (Hypertext Transfer Protocol) governs communication between clients and servers on the web. It defines the structure and format of requests and responses.

### Key Terms

- **Client-Server Architecture**: Clients (e.g., browsers) send requests; servers respond.
- **HTTP Verbs**:
  - `GET` → Retrieve a resource.
  - `POST` → Create a new record.
  - `PUT` → Update an existing resource.
  - `DELETE` → Remove a resource.
- **Request Headers**: Provide metadata for requests.
  - `User-Agent` → Info about the requesting client.
  - `Content-Type` → Data type (e.g., `application/json`).
  - `Accept` → Media types acceptable in the response.
  - `Authorization` → Credentials for protected resources.
  - `Cache-Control` → How responses should be cached.
  - `Cookie` → Sends cookies along with requests.
- **HTTP Status Codes**: Indicate request outcome (e.g., `200 OK`, `404 Not Found`).
- **URL**: Uniform Resource Locator — specifies the resource address.

## Making Basic HTTP Requests

Install requests:

```bash
pip install requests
```

Let’s use `https://jsonplaceholder.typicode.com/posts/` as our demo API.

### 1. Simple GET request

```python
import requests

url = "https://jsonplaceholder.typicode.com/posts/1"
response = requests.get(url)

print(response.status_code)   # 200
print(response.json())
```

Explore response properties:

- **`status_code`** → HTTP status code (`200` = success).
- **`content`** → Raw response body (bytes).
- **`text`** → Response decoded as Unicode string.
- **`json()`** → Parses JSON into Python dict/list.
- **`headers`** → Metadata about the response.
- **`request`** → The request object used.

```python
print(response.headers)
print(response.request.headers)
```

### 2. POST, PUT, DELETE requests

**POST** (create a record):

```python
url = "https://jsonplaceholder.typicode.com/posts/"
request_body = {
    "title": "new_blog",
    "body": "new_blog is new blog",
    "userId": 1
}

response = requests.post(url, json=request_body)
print(response.status_code, response.json())
# 201 Created
```

> 🔑 `json=` sets `Content-Type: application/json` automatically. Use `data=` for form-encoded payloads.

**PUT** (update a record):

```python
url = "https://jsonplaceholder.typicode.com/posts/1"
request_body = {
    "id": 1,
    "title": "new_blog_updated",
    "body": "new_blog is new blog",
    "userId": 1
}

response = requests.put(url, json=request_body)
print(response.status_code, response.json())
# 200 OK
```

**DELETE** (remove a record):

```python
url = "https://jsonplaceholder.typicode.com/posts/1"
response = requests.delete(url)
print(response.status_code, response.json())
# 200 {}
```

Alternative flexible API:

```python
requests.request("post", url, json=request_body)
requests.request("get", url)
```

## Using Headers in Requests

Sometimes APIs require extra info: XML instead of JSON, authentication tokens, or API keys. You can pass these via headers:

```python
url = "https://verysecurexml.com/apis/create-resource/"

body = "<xml_data>data</xml_data>"
token = "<token>"
headers = {
    "Content-Type": "application/xml",
    "Authorization": f"Token {token}",
    "X-API-Key": "<api_key>"
}

response = requests.request("delete", url=url, headers=headers, data=body)
print(response.status_code, response.text)
```

## HTTP Status Codes

- **1XX Informative**: `100 Continue`
- **2XX Success**: `200 OK`, `201 Created`, `204 No Content`
- **3XX Redirection**: `301 Moved Permanently`, `302 Found`, `304 Not Modified`
- **4XX Client Errors**: `400 Bad Request`, `401 Unauthorized`, `403 Forbidden`, `404 Not Found`
- **5XX Server Errors**: `500 Internal Server Error`, `502 Bad Gateway`, `503 Service Unavailable`

---

## Handling Errors

Always handle errors gracefully:

```python
import requests

url = "https://jsonplaceholder.typicode.com/posts/"
request_body = {"title": "new_blog", "body": "sample", "userId": 1}

try:
    response = requests.put(url, json=request_body)
    response.raise_for_status()
except requests.exceptions.HTTPError as err:
    print(f"HTTP error: {err}")
except requests.exceptions.RequestException as err:
    print(f"Connection error: {err}")
else:
    print(response.json())
```

- **`raise_for_status()`** → Raises `HTTPError` on non‑2xx status.
- **`RequestException`** → Catches connection/timeouts.
