## Intuition

Multiplication is just repeated addition. But since we can’t use +, we first need a way to add without + or -.

From our previous article, we already know how to do this with XOR magic (full adder logic):

```python
def add_no_plus_minus(a, b):
    while b != 0:
        carry = a & b
        a = a ^ b
        b = carry << 1
    return a
```

---

## Bitwise Multiplication

In binary, multiplication is just shifts and additions.

```
13 × 11
= (1101) × (1011)

= (1101 × 1) 
+ (1101 × 1 << 1) 
+ (1101 × 1 << 3)
```

---

## Implementation

```python
def add_no_plus_minus(a, b):
    while b != 0:
        carry = a & b
        a = a ^ b
        b = carry << 1
    return a

def multiply_no_star_plus(x, y):
    result = 0
    shift = 0
    
    # Handle negative numbers
    negative = (x < 0) ^ (y < 0)
    x, y = abs(x), abs(y)
    
    while y > 0:
        if y & 1:
            result = add_no_plus_minus(result, x << shift)
        shift = add_no_plus_minus(shift, 1)
        y >>= 1
    
    return -result if negative else result

print(multiply_no_star_plus(6, 7))    # 42
print(multiply_no_star_plus(15, 3))   # 45
print(multiply_no_star_plus(-4, 5))   # -20
print(multiply_no_star_plus(-6, -8))  # 48
```

## Example: 13 × 11

```
LSB of 11 → 1
Add (13 << 0) = 13
Result so far = 13

Next bit of 11 → 1
Add (13 << 1) = 26
Result so far = 13 + 26 = 39

Next bit of 11 → 0
Skip (since bit is 0).
Result so far = 39

Next bit of 11 → 1
Add (13 << 3) = 104
Result so far = 39 + 104 = 143
```

```
       1101   (13)
×      1011   (11)
-----------------
       1101   (13 << 0)
+     11010   (13 << 1)
+   1101000   (13 << 3)
-----------------
   10001111   (143 in binary)
```

This example shows how each bit of the multiplier controls whether we add a shifted version of the multiplicand — exactly how binary multiplication works inside CPUs.
